Settings

Use wss:// on https sites (like the default public server) and ws:// on http sites (like localhost). Wrong scheme = pages won't load. The default server is a third-party community instance — self-host a wisp server (this repo ships one) for reliability.

ripple

A fast web proxy with a monochrome-smooth interface. Powered by Ultraviolet over the wisp protocol with the epoxy transport. This static build runs entirely in your browser and tunnels through a remote wisp server — set your own under Settings.
